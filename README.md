# Swetty Huar - متجر الحلويات وحزم المطاط

هذا موقع ويب ثابت بسيط لمتجر Swetty Huar الذي يبيع الحلويات وحزم المطاط.

## الميزات

- الصفحة الرئيسية مع معلومات المتجر
- قوائم المنتجات للحلويات وحزم المطاط
- معلومات الاتصال
- تصميم متجاوب

## الإعداد

1. افتح ملف `index.html` في متصفح الويب لعرض الموقع.
2. لخادم محلي، يمكنك استخدام Python: `python -m http.server 8000` ثم زيارة `http://localhost:8000`.

## ملاحظات

- الصور هي عناصر نائبة ويجب استبدالها بصور المنتجات الفعلية.
- معلومات الاتصال خيالية ويجب تحديثها بتفاصيل حقيقية.
- الموقع مبني بـ HTML و CSS و JavaScript البسيط للبساطة.

## التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript
